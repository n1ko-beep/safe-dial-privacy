Privacy Policy for Safe Dial Wear OS game
Privacy Policy – Safe Dial

Effective date: 2026

Safe Dial is a simple puzzle game designed for Samsung Galaxy Watch devices.

1. Information Collection

Safe Dial does not collect, store, or share any personal data.

The application:

does not require user registration
does not collect personal information
does not access contacts, location, or device identifiers
2. Permissions

Safe Dial uses only standard system features required for gameplay, such as:

touch input
rotating bezel input (on supported devices)
vibration feedback

No additional permissions are required.

3. Data Usage

Since no personal data is collected, no data is processed, stored, or shared with third parties.

4. Third-Party Services

Safe Dial does not use any third-party services, analytics, or advertising SDKs.

5. Children's Privacy

Safe Dial does not knowingly collect any information from children. The app is safe for general audiences.

6. Changes to This Policy

This Privacy Policy may be updated in the future. Any changes will be reflected on this page.
